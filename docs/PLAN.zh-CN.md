# 分析计划（PLAN）

目标：用公开数据、纯计算的方式，学会"怎样评估一个衰老时钟而不自欺"。这是学习与可复现性项目，不是新发现，也不是医学结论。

## 一、步骤分解（对应 `scripts/`）

1. **下载**（`01_download.sh`）：GEO 已处理矩阵，不碰 IDAT；可续传，`gzip -t` 校验，记录 sha256。
2. **取时钟 CpG 列表**（`02_clock_features.py`）：从 pyaging 读取每个时钟的元数据与特征（CpG）列表，取并集（约 2.2 万个）。
3. **解析**（`03_parse.py`）：流式分块读取，只保留时钟所需 CpG 的 beta 矩阵，同时对全部 cg 探针做 QC（每样本 NA 比例、平均 beta），解析年龄/性别。
4. **跑时钟**（`04_run_clocks.py`）：pyaging 的 `predict_age`；自行统计每个时钟缺失 CpG 比例（pyaging 对缺失特征用参考值或 0 代替，只给警告）；个别 NA beta 按 CpG 用队列均值填补。
5. **评估**（`05_evaluate.py`）：MAE、中位 AE、RMSE、R²、Pearson/Spearman、平均带符号误差；按年龄段、性别分层；预测-实际图、残差-年龄图。DunedinPACE 与表型年龄类时钟不当作"年龄预测"来评 MAE。
6. **（选做）自训练**（`06_train_elasticnet.py`）：GSE40279 内先划分 → 只用训练集拟合填补/标准化 → ElasticNetCV → 冻结 → 外部测试 GSE87571，不重新拟合。

## 二、训练重叠核查（2026-11-11，来自论文原文/pyaging 元数据）

|---|---|---|---|
| Hannum 2013 | **yes** | no_evidence | 模型在 GSE40279 内部推导（482）和验证（174） |

## 三、已知坑

1. **训练泄漏**：在训练过该时钟的队列上测，只是复现检查（本项目里 Hannum、Horvath、Lin 在 GSE40279 都是如此）。自训练模型要先划分、再做任何特征选择和缩放。
2. **队列间批次/预处理差异**：GSE40279 与 GSE87571 的归一化流程不同（`mean_beta` 与 NA 模式不同）；时钟系数是在特定预处理下拟合的，换了预处理就会出现整体偏移。尚未做 BMIQ、探针类型校正、批次校正。
3. **缺失 CpG 的填补**：pyaging 对整个缺失的 CpG 用参考值/0 代替，会悄悄改变预测。本次各时钟缺失比例 ≤ 0.26%，影响应该很小，但 PC 时钟、EPIC 时钟（如 DunedinPACE 是 EPIC 设计）在 450K 上的覆盖需要单独检查。个别 NA beta 按 CpG 取队列均值填补，这依赖队列分布本身。
4. **血液细胞组成混杂**：年龄相关的 CpG 变化里有一部分只是白细胞比例（如幼稚/记忆 T 细胞、中性粒细胞比例）随年龄变化。已做后验分析（见 README「血细胞组成分析」）：Hannum、DNAmPhenoAge、DunedinPACE 的年龄加速与估计的 CD4T/粒细胞比例有稳定相关（|r| 约 0.2–0.33），细胞比例解释 Hannum 加速方差约 13%，IntrinClock 约 1%。但细胞估计本身有偏差（与保存者估计的 CD8T r 仅 0.66；PBMC 样本粒细胞估计 0.12 而应接近 0），且没有做亚型（初始/记忆 T 细胞），所以仍不能说"表观遗传年龄反映细胞内在衰老"。
5. **时钟加速 ≠ 寿命证据**：预测年龄与实足年龄之差，需要有死亡/疾病结局的纵向队列才能谈风险；本项目没有结局数据，不做这类结论。时钟"回拨"也不等于真正变年轻（可能只是细胞组成或校准变化）。
6. **回归向均值与年龄范围**：多数时钟在高龄偏低、低龄偏高，GSE87571 含 14–30 岁，而 Hannum/Horvath 等主要面向成人，所以不同年龄段的偏差不能混在一起看（见 `residuals_by_age_bin.csv`）。
7. **样本数与非独立性（已核查）**：GSE87571 的 732 条 = Johansson 2013 的 421 例 + 追加的 311 例（Ahsan 2017，同一 NSPHS 队列），其中 3 条无年龄/基因型/吸烟信息，评估用 729 个个体。没有发现重复个体（104 个基因型位点 + 2.2 万 CpG 的相关性检查），但队列人口较封闭，可能有亲缘个体，没有去除。两个 Sample_Group 批次之间时钟偏差差别可达 2–2.5 年（且年龄分布不同、未校正批次），是跨批次比较的一个提醒。
8. **"重校准"与"原始误差"是不同的问题**：原始 RMSE 的排名与线性重校准后的排名几乎不相关（Kendall τ 0.07 / 0.20）。比较时钟时要先说清楚比的是"出厂即用的误差"还是"去掉整体偏移/斜率之后的信息量"。

## 四、建议的下一步（按性价比排序；第 2、3 项相比上一版已部分完成）

1. **核对训练集清单**：把 SkinAndBlood、IntrinClock 的"unknown"逐项查清，并把 Horvath 补充表 1 里的 GEO 编号机器可读化，使 `training_overlap` 列有可检验的证据。
2. **提高细胞估计的可信度**（原计划的"统一预处理再评估"现在更具体）：对参考与两个队列用同一套归一化（例如 noob/BMIQ 或联合分位数归一化）重新估计；加入亚型（初始/记忆 CD4T/CD8T），并用 CD8T 估计差（r = 0.66）做敏感性分析；重做加速与细胞的相关表，看哪些相关能稳定存在。
3. **加一个真正独立的第三队列**：选一个不在上述任何时钟训练清单里的公开全血 450K/EPIC 队列（例如 GEO 上较晚发布的），重做 `metrics.csv` 和细胞分析，看排名与"哪些时钟对细胞组成敏感"是否稳定。
4. **在 GSE87571 里处理批次与亲缘**：把 `Sample_Group`、板/芯片号（保存者表里有 `Slide`、`chip:ass`）作为协变量，估计批次对时钟偏差的贡献；用基因型估计亲缘关系，去掉近亲后重算指标。
5. **把自训练模型做扎实**：嵌套交叉验证（缩放放进 CV 内部）、不同面板（时钟并集 vs 全探针 vs 稳定探针）、按年龄分层划分，并报告置信区间；可以再比较"加不加细胞比例作为协变量/训练前去除细胞效应"，目标是理解泛化而不是刷 MAE。
